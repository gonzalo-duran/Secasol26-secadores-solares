Why are they bundled in this repo?
----------------------------------
The PDF report generated by `ui/reporte.py` uses ReportLab. ReportLab's
default font (Helvetica, PostScript Type 1) lacks glyphs for `Δ`, `→`,
`η`, `−` and other characters we use in the report (sub-índices físicos,
flechas, letras griegas). DejaVu Sans covers all of them and ships with
a permissive redistribution license.

The fonts are loaded by `ui.reporte._registrar_fuentes()` at import time
with a fallback to the system DejaVu install if the bundled files are
missing, and ultimate fallback to Helvetica (which produces the original
glyph-missing artefacts).
